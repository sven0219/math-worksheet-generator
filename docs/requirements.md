# 产品需求与实施计划

> 本文档记录需求与验收标准；功能是否完成以代码及验证结果为准。对外项目简介与 Fork 部署步骤见 `README.md`。

## 功能

- 选择 **50 题**或 **100 题**；每 50 题排在一张 A4 纸上。
- 选择 50 题时可指定 1～10 份，分别生成不同的 50 题试卷（而不是将同一页重复打印）；100 题模式只能生成 1 份。若当前约束无法保证每份题目不同，禁止打印并提示调整条件。
- 选择 **5、10、20、50、100、200 以内**，或输入 **2～200** 的自定义整数上限。旧试卷二维码中已生成的更大范围题目仍应能显示原答案。
- 加、减、乘、除可多选；一年级默认使用加减法。
- 提供保守的年级与难度预设：幼小衔接为 10 以内两数字加减，一年级上为 20 以内两数字加减，一年级下为 100 以内两数字加减，二年级为 100 以内两数字四则；进退位均默认随机。应用预设不改变题量、打印份数、纸张和答案页，用户随后仍可修改各项，修改后显示为自定义设置。
- 加法可分别选择随机、不进位或必须进位；减法可分别选择随机、不退位或必须退位。进位、退位按十进制任一数位是否需要进位或借位判断；3～4 个数字时，每一步加减运算都必须满足对应设置。条件无法生成任何题目时应提示用户放宽范围或规则，不能生成不符合设置的占位题。
- 每题可设置 **2、3 或 4 个数字**。多数字算式不使用括号；混合运算按先乘除、后加减及同级从左到右的常规顺序生成和求值。
- 每张卷尽量避免重复题；题目组合不足时给出提示，而不是无限等待。
- 在网页上预览试卷，点击按钮重新随机生成，或打印当前试卷。
- 设置区分为 **快速开始** 与 **高级设置** 两档，默认快速开始：年级预设、题量与三种常用纸张（清爽白纸、数学方格、整齐横线），并提示当前配置可直接打印。高级设置中，最上方显示完整题型选择器，所有题型可见，选中项以颜色和勾号标识；其余按“基础计算、题型专项、生活数学、打印设置”四个标签分离，切换只改变可见设置，不改变题目，顶部选择器与标签页内题型状态同步。高级设置中四个标签上方显示可修改的基础数字范围并说明专项例外；选自定义上限进入基础计算详细项。快速开始与高级设置共用同一套出题状态。题型多选后在总题量中尽量均匀分配（数量最多差 1 题），并随机打乱。
- 题型包括口算、缺项填空、数字或算式比较大小、填运算符、2～9 口诀的乘除/缺项正反练习、加减乘除竖式、有余数除法，以及时间、人民币、单位、同分母分数和一位小数加减。
- 缺项随机隐藏任一数字或最终答案，数字缺项在合法范围内必须唯一；填运算符使用加减乘除且只能有一个正确符号。多个空在答案页按位置顺序显示，不给完整等式末尾重复添加等号。
- 纸张底纹（默认白纸版）：**白纸版**简洁留白；**数学方格**与**大方格**整页浅色格子（大方格间距更疏）；**横线版**与**双线本**（成对横线便于写算式）；**点阵版**整页浅色点阵；**田字格版**整页田字辅助线；**米字格版**整页米字辅助线。底纹在整张纸上，不应只在等号后面出现；样式只改变卷面，不改变题目内容或 A4 纸张规格。
- 每张纸上方留出**姓名、日期、年级、得分、用时**的填写位置；可选为**每份试卷**额外打印一张 A4 答案纸，50 / 100 题的答案均集中在该份对应的这一张，默认不打印答案。

## 出题约束

口算、缺项、比较、填运算符和竖式的“N 以内”为：参与运算的数字、中间结果和最终答案均为 **0 到 N** 的整数。普通除法必须整除，除数不能为 0；最终答案及中间结果均不能为负数。一位小数加减以十分之一为单位进行整数计算，数字与结果均不超过 N；不套用整数进退位规则。

- 有余数除法：范围至少 3，除数为 2～9 的可用整数，商至少 1，余数严格大于 0 且小于除数；被除数、除数、商和余数均不超过 N。
- 口诀固定因数为 2～9，可选口诀段，乘积不超过 81；不使用基础计算的上限。
- 时间采用整点、半点、30/60/90 分钟的经过时间（24 时制，不跨日）以及 1～12 小时的时分换算。
- 人民币金额不超过 20 元，包含元角分双向换算（最多 2000 分）；单位换算包括米/厘米、千米/米、千克/克、分米/厘米、厘米/毫米双向换算，大单位为 1～9 个（最多 9000 小单位）。
- 同分母分数加减：分母 2～9，数字与答案在 0～1，显示最简参考答案，等值形式也应视为正确。
- 以上专项范围在设置中明确提示，不用整数上限误标生活数学试卷。

## 网页界面

- 视觉风格活泼、友好，使用明亮但协调的多种颜色区分设置、试卷预览与主要操作；避免颜色过多导致页面凌乱，面向一年级孩子和陪同操作的家长。
- 用清楚的文字和简洁图形表达题量、范围、运算方式及卷面样式；不只靠颜色传达选中状态或错误信息。
- “生成新试卷”和“打印试卷”应醒目且易于点击；表单文字和触控区域适合手机、平板与电脑使用。
- 预览区域接近实际纸张的样式，切换卷面样式时能直接看到效果。动画可有但不能影响阅读、操作或打印，尊重减少动态效果的系统设置。
- 保持文字、按钮与背景的可读对比度；屏幕上的丰富色彩不应带入打印试卷的大面积背景，避免费墨或遮挡手写区域。
- 每张打印试卷右上角显示**该份试卷的专属二维码**，二维码**左侧**标注“**扫码看答案**”，页码放在二维码下方；扫码打开当前可访问的站点（包括 Fork 站点），网页展示这份试卷按题号排列的算式与答案。多份试卷分别有各自的二维码；100 题的两页使用同一个二维码。二维码不得依赖服务端保存题目，网址里的版本与种子必须可重现对应卷面。本站自定义域名定为 `math.svenshen.me`。DNS 未生效前不能把二维码硬编码到不可访问的域名。
- 扫码打开的答案页顶部提供醒目的“**我要出题**”按钮，点击返回本网站的出题首页，方便看完答案后生成自己的练习卷。
- 手机答案页的答案应紧跟算式，不应被推到卡片最右边；电脑答案页应根据算式长短使用合适列数，避免一个等号单独换行。

## 打印要求

- 使用 A4 纵向版式，每页固定 50 题；100 题恰好分成两页。
- 两个数字的基础题在空间允许时优先排成三列，减少两列布局的空旷感；多数字或较大范围题用两列保留可书写空间，仍然每页固定 50 题。
- 纯竖式页面仍按用户确认的每页 50 题，使用五列十行紧凑版，竖式数字按数位对齐，除法提供商位置与除法框；剩余区域用于书写计算过程。混合卷使用两列，夹杂的竖式压缩到单题高度，不额外拆页。必须提示书写空间有限，复杂过程可另用草稿纸。
- 题目区域留有手写答案的空间；每页都有填写栏与页码。
- 姓名等信息栏的下边线与第一行题目之间留有明显间距；打印内容需在移动端系统可能附加的页边距内排下，不因末页分页符产生空白页。
- 八种底纹使用相同的题目区域、分页和基本可书写空间；整页辅助线不能遮挡算式，等号后留有空白书写区，打印预览应与实际选择一致。
- 方格、虚线、点阵与田字格不能只依赖浏览器的“打印背景图形”选项；应采用在常见浏览器中默认也能打印的线条或点实现，并检查它们不会太密或太深。
- 打印时隐藏网页的设置和操作按钮；若选择打印答案，每份试卷（50 / 100 题）只增加一张答案 A4，按题号查找答案，不混入练习卷。多份试卷的答案页排在所有题目页之后，且注明对应份数。
- 验收时分别对八种样式在浏览器打印预览中检查 A4、100% 缩放和关闭浏览器页眉页脚后的分页与辅助线效果。不同浏览器或打印机设置仍可能影响实际版面。

## 实施顺序

1. 搭建纯前端项目，配置 GitHub Pages 部署（计划使用 Vite + TypeScript）。
2. 实现出题规则及自动测试，覆盖边界值、非负中间结果、整除和题目不足等情况。
3. 实现适合孩子操作的彩色响应式界面、选项设置、八种卷面样式切换、重新生成、预览与答案页。
4. 完成八种样式的 A4 打印版式，分别验证 50 / 100 题的分页、答题空间与辅助线。
5. 将 `README.md` 中预计的 Fork 部署步骤替换为实际验证过的步骤。

完成后应能够在任意受支持的设置下生成有效试卷；八种卷面样式的 100 题打印时题目部分都严格按每页 50 题分页，每页都能填写基本信息。
